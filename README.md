# Web development learning projects

Practice projects from an online web development course (HTML, CSS, JavaScript and Bootstrap), built in
December 2024 to March 2025. They are kept together here as a record of where I started. My current
work is the [faceless-channel](https://github.com/Saxissi/faceless-channel) video pipeline.

| Project | What it is | Skills practised |
|---|---|---|
| [drum-kit](projects/drum-kit) | A drum kit that plays a sound on each key press or click | JavaScript events, audio, DOM |
| [simon-game](projects/simon-game) | The Simon memory game | JavaScript game logic, jQuery-style DOM updates |
| [tindog-landing-page](projects/tindog-landing-page) | A responsive landing page | Bootstrap layout, responsive design |
| [html-resume](projects/html-resume) | A one-page HTML resume with a contact page | HTML structure, CSS styling |
| [html-portfolio](projects/html-portfolio) | A small multi-page portfolio site | Multi-page HTML and CSS, assets |

Each folder opens as a static site: open its `index.html` in a browser.

Note: some layouts and starter assets came from the course exercises; the code was written while following along.
